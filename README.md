# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

## 开局冲突复核

在详情页选择实际人数和今晚可用时长后生成待确认清单：

- 人数不在支持范围、预计时长超过今晚窗口时，必须逐项确认，否则不得记为已玩；
- 仍有争议规则时，必须为每条争议填写处理结论，结论自动转入"容易忘的规则"，原争议进入"争议归档"保留；
- 修改人数或时长后复核作废，需重新生成清单；
- 清单全部确认后才能记录开局，摘要、列表、统计和本地数据同步更新，刷新页面后复核进度继续。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。
