# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

## 开局冲突复核

选择桌游并填好实际人数、今晚时长后，点击详情里的「复核开局」生成待确认清单：

- 人数不在支持范围、预计时长超过今晚窗口、仍有争议规则，都会列入清单，未确认前不得记为已玩；
- 争议必须填写处理结论才能确认，确认后自动转为「容易忘的规则」，原争议保留在「争议归档」中；
- 复核中修改人数或时长会重新生成清单，需要重新逐项确认；
- 清单全部确认后才能点击「记录开局」更新上次游玩时间。

复核进度、归档和统计数据都保存在 localStorage，刷新页面后可继续。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。
